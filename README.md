# Impossible World KG

A cinematic, immersive web experience built around a scroll-driven journey through an impossible landscape.

## Overview

This project creates the feeling of traveling through a surreal world of floating islands, towering monoliths, and vast mountain vistas. Instead of a conventional page layout, the experience is designed as a continuous visual sequence where scrolling controls time and motion.

## Features

- Scroll-based cinematic storytelling
- Immersive landscape visuals and motion
- High-fidelity frame-driven experience
- Minimal, integrated interface
- Built with React and Vite

## Project Structure

- `impossible-world/` — main application source and frontend setup
- `docs/` — project vision, roadmap, and technical notes
- `public/frames/` — frame assets used in the cinematic sequence
- `scripts/` — extraction utilities for building the experience

## Quick Start

```bash
cd impossible-world
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Goal

The project aims to feel more like a cinematic world than a traditional website, giving users a memorable, immersive sense of motion and discovery.
